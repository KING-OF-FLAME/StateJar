---

**Definition.** Restating a value that is already stored. The field is untouched; the repetition is noted.

**Why it exists.** A user repeating a number is usually emphasising it, not editing it. Treating a repeat as a write would churn the handle for no change in meaning.

**Where you see it.** In the `reinforced` list. The handle does not move, because the state did not.

**Worked example.** `Budget is 5000` then later `remember, 5000 is the limit`. No supersession, no new version, no change line.

**Common misunderstanding.** That repeating a value is required for it to stick. It is not — one clear statement is enough.
