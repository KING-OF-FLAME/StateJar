**Environment variable:** `OPENAI_BASE_URL`

**Default:** `https://api.openai.com/v1`


Where OpenAI requests are sent.

Change it for Azure OpenAI, a self-hosted gateway, or any OpenAI-compatible
endpoint. See [OpenAI](#provider.openai).
