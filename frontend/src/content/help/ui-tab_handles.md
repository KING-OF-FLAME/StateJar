One row per state version, each with its handle. Click a row to inspect that
historical state — the panel switches to *Inspecting historical state* and a
**back to latest** control returns you.

Inspecting is read-only and changes nothing. To actually adopt an old state,
copy its handle and [restore it](#ui.restore_handle).

See [handle](#concept.handle) and
[active state vs history](#concept.active-vs-history).
