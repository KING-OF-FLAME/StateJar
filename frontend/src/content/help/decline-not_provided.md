**What it means.** You referred to something without saying what it is —
`I still need to work out the venue`, `budget TBD`.

**Not a decline.** Nothing was rejected. This is StateJar noting an *open*
field: a thing you have signalled matters, with no value yet.

**Where you see it.** The `unresolved` list, not
[`_unmapped`](#concept.decline).

**Why it is useful.** A model can be told what is still outstanding without
being told a made-up value for it.
