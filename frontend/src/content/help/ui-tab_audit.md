The per-session view of the audit trail: one row per disclosure with the handle
used, the field keys sent, and the provider and model they went to.

A row appears only when state was actually disclosed. A plain
`/memory/query` — the panel-only lookup — writes no audit row, because nothing
left the system.

The account-wide version is the [Audit Log screen](#ui.audit_log).
