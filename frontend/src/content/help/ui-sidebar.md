The left rail is the whole console.

- **Dashboard** — counts and the last chat's savings. See [Dashboard](#ui.dashboard).
- **Playground** — where you actually use StateJar. See [Playground](#ui.playground).
- **API Keys** — provider keys and your own StateJar API keys. See [API Keys](#ui.api_keys).
- **API Docs** — the endpoint reference with runnable samples. See [API Docs](#ui.api_docs).
- **Audit Log** — every disclosure across every session. See [Audit Log](#ui.audit_log).
- **About** — what StateJar is and what it does not do yet. See [About](#ui.about).
- **Help** — this centre. See [Help](#ui.help).

**Log out** sits at the bottom. It clears the chat transcripts stored in this
browser as well as your token, because those transcripts are held client-side
and a shared machine must not hand them to the next person.
