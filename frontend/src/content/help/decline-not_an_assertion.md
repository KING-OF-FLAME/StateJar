title: Declined: not an assertion
category: reference
updated_at: 2026-08-04
summary: The clause was a question, a negation or a retraction, not a claim.
keywords: not assertion question negation declined polarity
---

**What it means.** Something that looked like a fact was not being asserted.

**Why it happens.** `Is the budget still 5000?` contains a value but claims
nothing. `The deadline is not March 3` denies one. A
[retraction](#concept.retraction) withdraws one.

**What to do.** Nothing, usually — this is correct behaviour. Storing the
number in a question is how memory systems end up confidently wrong about
things the user was only asking about.

If you meant to assert it, say it as a statement.
