category: reference
updated_at: 2026-08-04
summary: A decision is explicitly outstanding.
keywords: pending outstanding waiting undecided unresolved
---

**What it means.** The clause said a value is coming but not yet settled —
`final hai nahi`, `still pending`, `waiting on confirmation`.

**Why it is tracked.** An assistant that knows which fields are pending can ask
about the right ones. An assistant that stored a guess cannot.

**What to do.** State the value when it is decided.
